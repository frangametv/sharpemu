# Istruzioni Git

- Quando crei un commit, non usare mai il branch `main`.
- Prima di eseguire il commit, assicurati che il branch attivo sia `XBuster`.
- Pubblica sempre le modifiche sul branch remoto `XBuster`, mai su `main`.

# Istruzioni Build

- Tutte le build del progetto devono essere generate nella cartella `D:\SharpEmu\SharpEmu-exe`.
- La cartella di destinazione deve contenere tutto il necessario per eseguire il progetto, incluse dipendenze, risorse e file di configurazione richiesti.
